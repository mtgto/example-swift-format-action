example-swift-format-action
====

Usage examples for [mtgto/swift-format-action](https://github.com/mtgto/swift-format-action).

- [`.github/workflows/lint.yml`](.github/workflows/lint.yml): Lint only
- [`.github/workflows/auto-correct.yml`](.github/workflows/auto-correct.yml): Format code automatically

`Sources/Example/Greeter.swift` is intentionally indented with 4 spaces, while `.swift-format` requires 2.
